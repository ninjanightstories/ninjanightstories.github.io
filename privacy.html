Privacy Policy

Ninja Night Stories Tools · Last updated: November 17, 2026

Who uses this application

Ninja Night Stories Tools is a private application used solely by the owner of the Ninja Night Stories YouTube channels to manage those channels. It is not offered to the public.

What data is accessed

With the channel owner's permission (Google OAuth, scope youtube.force-ssl), the application reads the list of videos and their titles, descriptions, tags and categories on the owner's own channels, and updates video descriptions to add support links.

How data is used and stored

  • Data is used only to perform the actions described above on the owner's own channels.
  • Access tokens and a list of processed video IDs are stored locally on the owner's computer.
  • No data is sold, shared with third parties, or used for advertising.
  • No data from viewers or other YouTube users is collected.

Google API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The application uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored tokens are deleted when they are no longer needed.

Contact

Questions about this policy can be sent via Patreon.
